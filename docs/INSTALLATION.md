# Установка и обновление

## Требования

Готовый выпуск 0.9.3: Mac с Apple Silicon (M1 и новее), macOS 14+. Проверка проведена на одном Mac; возможности датчиков зависят от оборудования. Xcode нужен только для сборки исходников.

## Установка DMG

1. Скачайте `MacPanel-v0.9.3-arm64.dmg` со страницы [релизов](https://github.com/rura-idk/MacPanel/releases).
2. Откройте образ и перетащите MacPanel на ярлык Applications («Программы»).
3. Откройте установленное приложение. Оно работает через значок в строке меню; основного окна и значка Dock нет.
4. Извлеките образ после копирования. Не запускайте постоянно приложение внутри DMG: для автозапуска оно должно находиться в «Программах».

Выпуск имеет локальную ad-hoc подпись, без Developer ID и нотарификации Apple. macOS может отказать в первом открытии. Только если вы доверяете источнику, после попытки запуска откройте «Системные настройки → Конфиденциальность и безопасность» и используйте разрешение для этого приложения по [инструкции Apple](https://support.apple.com/en-us/102445). При сообщении о вредоносном или повреждённом файле не игнорируйте предупреждение: скачайте файл заново и проверьте источник. Не отключайте защиту всей системы.

## Проверка скачанного файла

Рядом с DMG опубликован `SHA256SUMS.txt`. В Терминале в папке со скачанными файлами:

```bash
shasum -a 256 -c SHA256SUMS.txt
```

Ожидаемый результат для каждого скачанного файла — `OK`. Контрольная сумма проверяет совпадение файла с опубликованным, но не заменяет Developer ID или нотарификацию.

## Автозапуск

При первом запуске из «Программ» MacPanel пытается добавить себя в объекты входа. Проверяйте переключатель в «Настройки». Если macOS требует разрешение, откройте системные объекты входа через кнопку панели. В разных версиях macOS название системного раздела может отличаться.

## Обновление

Завершите старую версию через кнопку внизу панели, замените приложение в «Программах» и запустите его заново. История, закреплённые приложения и сохранённые команды остаются в пользовательской папке данных; их не нужно добавлять повторно. Автоматического обновления нет.

## Удаление

Отключите автозапуск, завершите MacPanel и удалите приложение из «Программ». Само удаление приложения не удаляет пользовательские данные. Историю можно заранее очистить в настройках панели; все сохранённые данные находятся в `~/Library/Application Support/MacPanel/`. Удаляйте эту папку вручную только если вам больше не нужны история и конфигурация.
