# Проверка перед выпуском

Записывайте фактически выполненные проверки. Доступность датчиков и работа на одном Mac не доказывают совместимость со всеми устройствами.

## Код и сборка

- [ ] Версия Info.plist совпадает с CHANGELOG и тегом.
- [ ] Собраны Swift-приложение и оба Objective-C помощника.
- [ ] `codesign --verify --deep --strict` проходит; тип подписи описан честно.
- [ ] DMG проходит `hdiutil verify`; опубликована SHA-256.
- [ ] Нет секретов, пользовательской конфигурации и персональных логов в Git и архиве.
- [ ] Сохранены MIT и сторонние уведомления.

## На Mac

- [ ] Установка из DMG в «Программы» и запуск; проверка ожидаемого поведения Gatekeeper.
- [ ] Значок строки меню, отсутствие основного окна и значка Dock.
- [ ] Раскрытие, сворачивание, смена раздела, прокрутка и повторное открытие панели.
- [ ] Реальные/недоступные показания датчиков корректно отображаются.
- [ ] Буфер: текст, изображение, файл, восстановление, пауза, очистка, сохранение между запусками.
- [ ] Выбор, запуск и удаление ярлыка приложения.
- [ ] Сохранение и запуск команды; Terminal показывает вывод и принимает интерактивный ввод.
- [ ] «Не засыпать» включается, выключается и освобождает assertions при выходе.
- [ ] Автозапуск, запрос разрешения, выключение и перезапуск входа в macOS.

## Публикация

- [ ] Название и описание release совпадают с артефактами и архитектурой.
- [ ] Для ad-hoc выпуска стоит отметка pre-release и нет обещания нотарификации.
- [ ] README и инструкции соответствуют версии.
- [ ] Скачивание и хэши проверены после публикации.
- [ ] Результаты CI просмотрены; неподтверждённые проверки явно отмечены.

Локально в 0.9.3 проверены сборка, подпись, DMG, основные действия панели, датчики на одном Mac и создание процесса Ollama из сохранённой команды. Пользователь подтвердил работу. Полная матрица устройств, чистая загрузка на другом Mac и независимый аудит безопасности не выполнялись.
