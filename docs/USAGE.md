# Использование

## Панель

Нажатие значка открывает панель. Нажатие заголовка раскрывает раздел под ним, повторное — сворачивает. При раскрытии другого раздела прежний закрывается. Длинные разделы прокручиваются. Щелчок вне панели закрывает её; приложение продолжает работать в строке меню.

## Система

Показатели обновляются периодически. Сеть и дисковая активность вычисляются по разнице счётчиков; сразу после запуска часть скоростей ещё не определена. Температура — доступный датчик SoC/PMU, а не обязательно самое горячее ядро. GPU и вентилятор зависят от доступности системных интерфейсов. Прочерк означает отсутствие показаний, а не нулевое значение.

## Буфер обмена

Пока приложение запущено, оно отслеживает изменения системного буфера и хранит до 15 записей. Нажмите запись, чтобы скопировать её обратно, затем вставьте обычным способом в нужное приложение. MacPanel не вставляет текст за вас. Изображения хранятся на диске; для файлов сохраняются ссылки, поэтому перемещение или удаление исходного файла может сделать запись непригодной. Доступны удаление записи и очистка истории с подтверждением. Пауза включается в настройках.

## Приложения и режим сна

«Добавить» открывает системный выбор приложений. Выберите приложение, затем запускайте его кнопкой в панели. Кнопка удаления убирает только ярлык из MacPanel, не само приложение.

«Не засыпать» действует, пока MacPanel запущен. Он не меняет постоянные настройки питания, не блокирует ручной сон, выключение и не гарантирует работу с закрытой крышкой MacBook.

## Собственные команды

1. Введите понятное название и текст команды.
2. Нажмите «Сохранить команду».
3. Нажмите появившуюся кнопку. Откроется штатный Терминал с этой командой.

Простой пример:

```bash
printf 'Hello from MacPanel\n'
```

Открыть текущий сайт в браузере можно командой `open https://github.com/rura-idk/MacPanel`.

Для локального чата Ollama, если Ollama уже установлена и доступен её сервис:

```bash
ollama run gemma4:12b
```

Название модели — пример; выберите доступную вам модель. Если её нет локально, Ollama может предложить/начать загрузку по своим правилам. MacPanel не включает Ollama и веса модели. Вводите сообщения в Терминале; выйти из чата Ollama можно командой `/bye`.

Выполнение начинается в домашней папке через login-shell zsh. Для другой папки укажите `cd '/путь/к/проекту' && ваша-команда`. Путь с пробелами заключайте в кавычки. Интерактивный zsh-конфиг `.zshrc` автоматически не загружается этим способом: псевдонимы из него могут отсутствовать. Используйте полный путь к программе или самостоятельный скрипт. Каждое нажатие запускает новый сеанс; остановка процесса выполняется в Терминале.

Не вставляйте чужие команды, смысл которых вам неизвестен. MacPanel запускает их с обычными правами текущего пользователя и не изолирует в песочнице.
