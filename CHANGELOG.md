# История изменений

## 0.9.3 — 2026-11-01

- Пользовательские команды открываются в штатном Терминале с вводом и выводом. Исправлен запуск интерактивных программ, включая Ollama.
- Добавлены пути Homebrew и сообщения о результате открытия Терминала.
- Существующие сохранённые команды совместимы.
- Упрощён вывод типов в расчёте CPU для совместимости с компилятором Swift на GitHub Actions.

## 0.9.2 — 2026-11-01

- Полностью убрано отдельное основное окно. Работа только из строки меню.
- Разделы раскрываются вниз в одном системном popover и сворачиваются повторным нажатием.
- Проверены нажатия после изменения размера, поля ввода и системный выбор приложения.

## 0.9.1 — 2026-11-01

- Переработаны обработка событий и фокус элементов; промежуточная версия с нативным меню и отдельным окном настроек.

## 0.9.0 — исходная версия

- Мониторинг системы, история буфера, запуск приложений и команд, Keep Awake и автозапуск.
- В исправленной локальной сборке добавлено явное приведение двух констант IOKit к CFString, устраняющее ошибки компиляции.

Ранние версии не публиковались как GitHub Releases. Первый подготовленный публичный предварительный выпуск — 0.9.3.
