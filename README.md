# MacPanel

Утилита для macOS, которая объединяет мониторинг системы, историю буфера обмена, запуск приложений и команд в строке меню. Без отдельного основного окна и значка в Dock.

[English](README.en.md) · [Скачать](https://github.com/rura-idk/MacPanel/releases) · [Установка](docs/INSTALLATION.md) · [Использование](docs/USAGE.md) · [Вопросы и решения](docs/TROUBLESHOOTING.md)

**Текущая версия: 0.9.3, предварительный выпуск.** Собрана и проверена на Mac с Apple Silicon; пользователь подтвердил работу панели и команд. Готовый DMG предназначен для **Apple Silicon, macOS 14+**. Интерфейс на русском. Подпись локальная (ad-hoc), **Developer ID и нотарификации Apple нет**. Совместимость со всеми моделями Mac и версиями macOS не гарантируется.

## Возможности

| Раздел | Что умеет |
| --- | --- |
| Система | CPU, ядра и нагрузка, GPU при доступности, память и swap, температура, обороты вентилятора, тепловое состояние, сеть, место и активность диска, время работы |
| Буфер обмена | До 15 последних копирований: текст, изображения и ссылки на файлы. Повторное копирование записи, удаление и локальное хранение между запусками |
| Приложения | Закреплённые приложения, собственные команды в Терминале и режим «Не засыпать» |
| Настройки | Автозапуск, пауза истории, очистка истории и статус разрешения автозапуска |

Нажмите значок MacPanel в строке меню, затем название раздела. Содержимое раскроется **снизу в той же панели**. Повторное нажатие свернёт раздел; одновременно открыт один раздел. Длинное содержимое прокручивается. Системный popover и элементы SwiftUI/AppKit следуют оформлению macOS.

## Установка

1. Откройте [Releases](https://github.com/rura-idk/MacPanel/releases) и скачайте `MacPanel-v0.9.3-arm64.dmg`.
2. Откройте DMG и перетащите MacPanel в «Программы».
3. Запустите MacPanel. Панель появится у значка строки меню.
4. При обновлении сначала завершите прежнюю версию кнопкой «Завершить MacPanel».

Для готового DMG Xcode не нужен. Поскольку выпуск не нотарифицирован, macOS может заблокировать первый запуск. Если вы доверяете источнику, следуйте [официальной инструкции Apple](https://support.apple.com/en-us/102445); не отключайте Gatekeeper целиком. Подробности и проверка SHA-256: [инструкция установки](docs/INSTALLATION.md).

## Команды, включая Ollama

В «Приложения» заполните название и команду, нажмите «Сохранить команду», затем кнопку сохранённой команды. Команда открывается в штатном **Терминале** с доступным вводом и выводом. Сам MacPanel остаётся утилитой строки меню; Терминал — отдельное приложение, необходимое интерактивным командам.

Пример: `ollama run gemma4:12b`. Ollama и модель устанавливаются отдельно. Команды выполняются от имени текущего пользователя через `/bin/zsh -l`, начиная с домашней папки. В поиск программ добавлены `/opt/homebrew/bin` и `/usr/local/bin`. Ошибки команды видны в Терминале; ошибка открытия Терминала — в панели. Запускайте только понятные вам команды. См. [примеры](docs/USAGE.md).

## Ограничения и данные

- **Датчики:** используются в том числе недокументированные интерфейсы IOKit/SMC. На другом Mac или macOS часть показателей может быть недоступна; отображается `—`. Управления вентилятором нет, только чтение.
- **Не засыпать:** предотвращает сон от бездействия через IOKit. Закрытие крышки MacBook всё равно может вызвать сон. При выходе и перезапуске режим выключается.
- **Буфер:** сохраняется локально в `~/Library/Application Support/MacPanel/Clipboard/`, без собственного шифрования. Конфиденциальные записи с соответствующими метками пропускаются, но это не гарантирует исключение паролей. Историю можно приостановить и очистить. Очень быстрые копирования могут быть пропущены.
- **Автозапуск:** при первом запуске из «Программ» приложение пытается зарегистрировать вход через SMAppService. Может требоваться разрешение macOS. Системные настройки имеют приоритет.
- В MacPanel нет встроенной аналитики и загрузки буфера в сеть. Пользовательские команды и запускаемые приложения могут обращаться к сети по своему назначению.

Подробнее: [конфиденциальность](PRIVACY.md) и [безопасность](SECURITY.md).

## Сборка из исходников

Нужен Mac с macOS 14+, Xcode с установленными инструментами командной строки и Swift 5.9+. Внешних Swift-пакетов нет.

```bash
git clone https://github.com/rura-idk/MacPanel.git
cd MacPanel
bash build.sh
open dist/MacPanel.app
bash scripts/make-dmg.sh
```

Результат: `dist/MacPanel.app` и `dist/MacPanel.dmg`. По умолчанию собирается архитектура текущего Mac, подпись ad-hoc. `MACPANEL_ARCH=x86_64 bash build.sh` доступно для разработчиков, но Intel-сборка не проверялась и в этот выпуск не включена.
