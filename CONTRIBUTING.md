# Участие в разработке

Проект находится на стадии предварительного выпуска 0.9.3. Проверки проведены на одном Apple Silicon Mac; отчёты о других моделях и версиях macOS приветствуются.

1. Создайте issue с версией MacPanel, macOS, моделью устройства, шагами воспроизведения и ожидаемым результатом.
2. Не публикуйте историю буфера, токены, приватные команды, серийные номера или полные персональные пути.
3. Для изменения кода создайте отдельную ветку и pull request. Опишите проблему, изменение поведения и выполненную проверку.
4. Выполните сборку на macOS и подходящие проверки из [DEVELOPMENT.md](docs/DEVELOPMENT.md).
5. Сохраняйте сторонние уведомления о лицензиях. По возможности используйте документированные API.

Цель: Swift 5.9+, macOS 14+, работа из строки меню с системными элементами управления. Не включайте данные пользователя, сборочные кэши, сертификаты или ключи в коммиты.
